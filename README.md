# Jerome Kuo × 凌全科技｜Infor ERP 顧問提案

為凌全科技 Infor ERP 企業顧問職缺製作的單頁提案網站。

## 互動頁面

- `index.html`：應徵提案首頁
- `demos.html`：ERP 顧問五項工作 Demo
- `fit-demos.html`：職缺能力情境 Demo
- `transformation-demo.html`：凌全 ERP／WMS／MES／AI 數位轉型整合 Demo

## 本機預覽

```bash
python3 -m http.server 4173 --directory lchange-erp-proposal
```

開啟 `http://localhost:4173`。

## 部署

純靜態 HTML／CSS／JavaScript，可直接部署至 GitHub Pages。
